
# Guess the Number Game

A simple and fun number guessing game where the player tries to guess a randomly generated number within a limited number of attempts.

# Overview

This project is a beginner-friendly game designed to practice logic building, random number generation, and user interaction. The player is prompted to guess a number between a chosen minimum and maximum range, and the game gives hints such as:

- Too high
- Too low
- Correct guess
- Attempts left

# Features

- Random number generation
- User input validation
- Hints for higher/lower guesses
- Limited attempts
- Score tracking
- Replay option
- Beginner-friendly code structure

# How to Play

1. Run the program.
2. Choose a range (optional, if your version supports it).
3. Enter your guess.
4. The game will tell you whether your guess is too high, too low, or correct.
5. Continue guessing until you find the correct number or run out of attempts.
6. You may choose to play again after the game ends.
